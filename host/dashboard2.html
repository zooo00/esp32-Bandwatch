    Bluetooth LE

    0 now
    NameAddressVendor What it looks likeTX pwrRSSIMax TrendAdvertsSeen

    BLE mode pauses Wi‑Fi sniffing (single radio). Vendor is the Bluetooth SIG company id from manufacturer data, or the OUI for public addresses. Most phones and wearables rotate random addresses every ~15 minutes, so the same device may appear under several addresses. The prebuilt radio stack scans legacy advertisements only.
